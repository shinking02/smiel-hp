## Communication

- Please use Japanese for conversation with humans.
- Keep your answers concise and be careful not to cause cognitive load.
- Clarify ambiguous instructions by asking questions.
- Do not proceed with implementation without user confirmation when asking questions or discussing things.

## Coding Style

- Avoid excessive comments and let the code speak for itself.
- Write comments only when there are intentions or backgrounds that cannot be inferred from the code.
- Strive to write concise comments in English.
- Maintain separation of concerns.
- Emphasize readability and maintainability.
- Strictly define the contract layer and keep the implementation layer reproducible.
- Always prefix Git commit messages and keep them in English within 50 characters.
